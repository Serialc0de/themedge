# Contributing

## Workflow Git

- `main` → produzione (protetto)
- `develop` → sviluppo
- `feature/*` → nuove funzionalità
- `fix/*` → bug fix

## Commit convention

Conventional Commits:

- `feat: nuova funzionalità`
- `fix: correzione bug`
- `docs: documentazione`
- `style: formattazione`
- `refactor: refactoring`
- `test: test`
- `chore: manutenzione`

## Pull Request

1. Branch da `develop`
2. Modifiche + test
3. `npm run lint` e `php artisan test`
4. PR con descrizione
